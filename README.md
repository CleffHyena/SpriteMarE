# SpriteMarE
SpriteMarE is a 'SuperMarionEtte' Augmented Reality film studio for beginners, built using open-source pro chroma/tracking tools.

Various free libraries and tools exist only professionals can use for AR filmmaking. SpriteMarE is a UI and set of apps that removes the computer literacy barrier.

Fantasy films can be brought alive from a concept in one room and sitting, without prior 3D training. Tablets and phones are used with Godot style paintbox apps, camera apps and live output to a world on a TV everyone onstage sees. All that is needed is:

• a powerful host computer
• tablet, phone, or drones, optional 6dof camera setup
• local networking
• 2 HDMI monitoring screens
• chromakey screen and lighting

Aiming to usable by all ages, for free, as a collaborative team, SpriteMarE is a playground anyone can fumble with before they can rumble with a full 3D engine.

I also want to integrate a course led by my own voice where user storywriting evolves from premade visual elements like they are Lego, as this helps 'uncreative' minds build confidence. The UK show Bamzooki from 2005 is a model for how this will work.

I will limit all of this to a standard definition, 1990s FMV, ReBoot, Parappa inspired look, that looks like the intro to a cereal box CD 'Art Attack' suite.

This consistent art style will streamline development goals, and my own fully drafted upcoming movie is the testbed for SpriteMarE. Stay Tuned!
